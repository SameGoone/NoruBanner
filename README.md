Реализация API (**ASP.Net**) + клиентского приложения (**React+TypeScript**) для баннера на странице с отслеживанием просмотров/кликов.

Реализована идентификация пользователя без авторизации, учитывается просмотр баннера на неактивной вкладке.

Добавлен файл **docker-compose** для развёртывания всей системы в Release-mode
