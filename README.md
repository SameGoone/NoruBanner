1. _**Заработает ли мой код, если на странице два баннера?**_

Добавляем bannerId в пропсы компонента Banner. Теперь каждому баннеру можно задавать свой идентификатор и добавлять их на страницу в любом количестве.

**_2. Как можно идентифицировать пользователя сайта с баннером?_**

**_А если сайтов будет несколько?_**

Идентификация на одном сайте:

Я решил использовать localStorage для хранения уникального ID пользователя. localStorage сохраняется в браузере между сессиями. Пока пользователь не очистит кеш браузера вручную, ID будет постоянным. Это решение **не** позволяет идентифицировать пользователя между сайтами.

Альтернативы:

- First-Party Cookies: автоматически отправляются на сервер с каждым HTTP-запросом.

Идентификация на нескольких сайтах:

- Third-Party Cookies - блокируются современными браузерами

- Фингерпринтинг - подпадает под GDPR/ePrivacy, требует оптимальной настройки по точности, но никогда не даст 100% результат

- Авторизованных пользователей можно однозначно идетифицировать, вне зависимости от браузера и домена.

С кросс-сайтным отслеживанием всё непросто и требует компромиссов.
